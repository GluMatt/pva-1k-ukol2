# Rock, Paper, Scissors Game

Write a program that lets the user play rock, paper, scissors against the computer. The user enters their choice, the computer picks one at random, and the program announces who won that round. Keep playing rounds until the user chooses to quit, then display the final score.

Requirements:

The computer's choice must be random each round.
Handle invalid input (e.g., misspelled or unrecognized choices) without crashing.
Track and display wins, losses, and ties.

Bonus: Play to a "best of five" match, or add the lizard and Spock variants.
Bonus 2: Add a mode where the computer wins every time
